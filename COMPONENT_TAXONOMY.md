# ComponentOS — Component Taxonomy & Catalog Specification

## Catalog Architecture
ComponentOS structures its catalog across 5 levels and 12 functional domains:

### Level 1: Foundations
- Design tokens, color palettes, typography scales, spacing tokens, radii, shadows, icons, animation primitives, breakpoints.

### Level 2: Micro Components (Primitives)
- Button, Icon Button, Text, Heading, Label, Badge, Tag, Avatar, Divider, Spinner, Loader, Skeleton, Progress, Tooltip, Kbd, Status Indicator, Dot, Chip, Counter, Breadcrumb Item.

### Level 3: Form Components
- Input, Textarea, Password Input, Search Input, Number Input, Currency Input, OTP Input, Date Input, Time Input, File Input, Image Upload, Checkbox, Radio, Switch, Toggle, Select, Multi Select, Combobox, Autocomplete, Slider, Range Slider, Date Picker, Date Range Picker, Time Picker, Color Picker, Rich Text Editor, Form, Form Field, Form Label, Form Description, Form Error.

### Level 4: Navigation & Feedback Components
- **Navigation**: Navbar, Header, Sidebar, Mobile Sidebar, Drawer, Bottom Navigation, Tabs, Breadcrumb, Pagination, Stepper, Navigation Menu, Command Menu, Mega Menu, Dropdown Menu, Context Menu.
- **Feedback**: Alert, Toast, Notification, Banner, Callout, Modal, Dialog, Confirmation Dialog, Alert Dialog, Popover, Tooltip, Empty State, Error State, Success State, Loading State, Maintenance State.

### Level 5: Data Display & Media
- **Data Display**: Card, Table, Data Table (sorting, filtering, pagination, selection), List, Grid, Timeline, Calendar, Activity Feed, Stats/KPI Card, Metric Card, Chart Container, Tree, Accordion, Collapsible, Description List, Comparison Table.
- **Media**: Image, Image Gallery, Carousel, Lightbox, Video Player, Audio Player, Avatar Group, File Preview, PDF Preview, Media Card, Drag & Drop Upload.

### Level 6: Advanced, Ecommerce, Dashboard, Auth & AI Components
- **Advanced**: Command Palette, Kanban Board, Date Range Selector, Rich Text Editor, Code Editor, JSON Viewer, Markdown Renderer, Terminal, Logs Viewer, Chat Interface.
- **Ecommerce**: Product Card, Product Grid, Product Gallery, Product Details, Variant Selector, Size Selector, Color Selector, Quantity Selector, Price Display, Discount Badge, Rating, Review List, Add to Cart, Cart Drawer, Checkout Steps, Product Filters.
- **Dashboard**: Dashboard Layout, Sidebar Dashboard, KPI Cards, Revenue Chart, Sales Chart, Recent Orders, Filter Bar, Date Range Toolbar, Dashboard Header.
- **Authentication**: Login, Signup, Forgot Password, Reset Password, OTP Verification, Social Login, Passkey UI, Security Settings.
- **AI**: AI Chat, Chat Message, AI Composer, Prompt Input, Streaming Response, Model Selector, Token Usage, AI Response Card, Reasoning Indicator, Source Citation, AI Code Gen Panel.

### Level 7: Multi-Component Blocks, Sections & Page Templates
- **Blocks**: Login Block, Signup Block, Pricing Block, Hero Block, Feature Block, FAQ Block, Contact Block, Newsletter Block, Testimonial Block, Footer Block, Analytics Block, Cart Block.
- **Sections**: SaaS Hero, Ecommerce Hero, Developer Hero, AI Hero, Pricing Section, Feature Comparison, Customer Logos, FAQ Section.
- **Templates**: SaaS Landing Page, Ecommerce Homepage, Admin Dashboard, Analytics Dashboard, Authentication Suite, Pricing Page, Documentation Page, AI Chat Application, Ecommerce Product Page, Checkout Page.
